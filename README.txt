WEBSITE PROFIL DESA NYIUR INDAH - VERSI 1
==========================================

TEKNOLOGI
- PHP Native 8.x+
- MySQL/MariaDB
- Bootstrap 5 via CDN
- PDO

INSTALASI XAMPP
1. Salin folder website_desa_nyiur_indah ke C:\xampp\htdocs\
2. Jalankan Apache dan MySQL di XAMPP.
3. Buka phpMyAdmin: http://localhost/phpmyadmin
4. Import file database.sql.
5. Buka: http://localhost/website_desa_nyiur_indah/
6. Panel admin: http://localhost/website_desa_nyiur_indah/login.php

LOGIN DEMO
Username: admin
Password: admin123

MENU ADMIN
Dashboard, Profil/Pengaturan, Berita, Pengumuman, Kegiatan, Potensi, UMKM,
Dokumen, Galeri, Pelayanan, dan Pengaduan.

CATATAN KEAMANAN
- Ganti password admin setelah instalasi.
- Untuk server online, gunakan HTTPS.
- Batasi ukuran/jenis file upload dan lakukan backup database secara rutin.
- Kredensial database berada di config/database.php.
